# Invest Pro 2.0 🚀

**Invest Pro 2.0** — це комп'ютерна система підтримки прийняття рішень (Decision Support System - DSS) у сфері інвестицій. Проект розроблений для автоматизації процесу аналізу активів, використовуючи математичне моделювання, алгоритми оптимізації портфеля та штучний інтелект.

Система дозволяє користувачеві формувати інвестиційний портфель на основі індивідуальних переваг (ризик, прибутковість, вартість, дивіденди), аналізуючи реальні біржові дані та новинний фон у режимі реального часу.

## 🌟 Ключові наукові та інженерні рішення

1. **Математичне моделювання (AHP алгоритм):**
   Метод аналізу ієрархій (Analytic Hierarchy Process) Томаса Сааті для визначення ваг критеріїв на основі попарних порівнянь.
   
2. **Оптимізація портфеля (Модель Марковіца):**
   Впроваджено симуляцію Монте-Карло (2000+ ітерацій) для побудови Ефективної межі (Efficient Frontier), пошуку портфеля з максимальною прибутковістю (Max Sharpe) та мінімальним ризиком (Min Volatility).

3. **Аналіз ризиків (Кореляційна матриця):**
   Обчислення взаємозв'язків між активами для забезпечення якісної диверсифікації та зниження системного ризику портфеля.

4. **Обробка природної мови (NLP Sentiment Analysis):**
   Інтегровано модель ШІ **VADER** для аналізу свіжих новинних заголовків та оцінки настроїв ринку (Sentiment Score).

5. **Бектестинг (Backtesting):**
   Алгоритм "Машини часу", що дозволяє перевірити результативність сформованого портфеля на історичних даних за останній рік.

## 🛠️ Технологічний стек

- **Backend:** Python 3.12, Django 5.1+
- **Frontend:** HTMX (плавні оновлення без перезавантаження), Bootstrap 5, JavaScript
- **Data Science:** NumPy, Pandas, yfinance
- **AI / NLP:** vaderSentiment
- **Візуалізація:** ApexCharts, TradingView Widget API
- **UX/UI:** Intro.js (онбординг), PWA (підтримка мобільного встановлення)
- **База даних:** SQLite3 / PostgreSQL

## 🚀 Основний функціонал

* **📊 Аналіз Акцій та Криптовалют:** Окремі модулі для фондового та крипто-ринків.
* **⚡ HTMX Driven UI:** Миттєва навігація та живий пошук тікерів без перезавантаження сторінок.
* **📈 Модель Марковіца:** Візуалізація ризиків та автоматична рекомендація оптимальних ваг.
* **🔗 Матриця Кореляції:** Інтерактивна теплова карта взаємозв'язків активів.
* **⏳ Історичний Бектест:** Розрахунок потенційного прибутку за минулий рік.
* **🔔 Система Сповіщень:** Можливість створення Alert-ів на цільову ціну активу.
* **❔ Інтерактивний Онбординг:** Покроковий гід для нових користувачів.
* **📲 PWA Support:** Додаток можна встановити на смартфон як нативну програму.
* **📋 Швидкий Експорт:** Вивантаження у PDF, CSV або швидке копіювання портфеля для Telegram/Viber з емодзі.

## ⚙️ Встановлення та запуск

1. **Клонування та налаштування:**
   ```bash
   git clone <URL_репозиторію>
   cd invest
   python -m venv venv
   source venv/bin/activate  # venv\Scripts\activate для Windows
   pip install -r requirements.txt
   ```

2. **База даних та запуск:**
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```

3. **Доступ:** `http://127.0.0.1:8000/`

## 📁 Структура проекту

* `analyzer/` - Логіка аналізу та Django-додаток.
  * `utils.py` - Математичне ядро (AHP, Markowitz, Backtest).
  * `views.py` - Контролери інтерфейсу.
  * `templates/` - Адаптивні HTML-шаблони.
* `invest_project/` - Налаштування проекту.
* `static/` - CSS, JS, PWA Manifest та іконки.
